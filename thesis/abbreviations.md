## Symbols (used in formulas in Chapter 4)

| Symbol | Meaning |
|---|---|
| *r* | Pearson correlation coefficient |
| *k₁*, *b* | BM25 hyperparameters (term-frequency saturation and document-length normalisation) |
| *τ* | Fuzzy-matching threshold (Levenshtein-similarity ratio) |
| idf(t) | Inverse document frequency of term *t* |
| *N*, *M* | Number of resumes and number of job descriptions in the evaluation set |
| *R*, *J* | A single resume and a single job description |
| *K*(·) | Keyword extractor function (returns the keyword set of an input) |
| dl, avgdl | Document length, average document length (BM25 normalisation) |
