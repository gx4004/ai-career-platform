## Symbols (used in formulas in Chapter 4)

| Symbol | Meaning |
|---|---|
| *r* | Pearson correlation coefficient |
| ρ, τ | Spearman and Kendall rank-correlation coefficients |
| *k₁*, *b* | BM25 term-frequency saturation and document-length normalisation parameters |
| *τ* | Fuzzy-matching similarity threshold |
| idf(t) | Inverse document frequency of term *t* |
| *N*, *M* | Number of resumes and number of job descriptions |
| *R*, *J* | A single resume and a single job description |
| *K*(·) | Keyword extractor function |
