## How to work

- New work: branch from `origin/integration/chapter2-narrowing` (or from `chapter2`
  once the single PR is merged); open draft PRs against that base; fold into the
  integration branch after checking diff, tests and screenshots.
- Delegate each issue to one subagent in its own worktree
  (`isolation: worktree`); at most 2–3 in parallel — heavier load makes Playwright
  flaky.
- **Alembic:** parallel branches each add a migration on the same parent. After every
  fold-in run `alembic heads`; if two heads, re-point the newer one's
  `down_revision` + `Revises:` docstring, then round-trip on a throwaway Postgres DB.
  A merge without conflicts auto-commits — commit follow-up edits separately.
