## The plan

Product direction was reset on **2026-09-24** after a months-long pause. The tracked
source of truth is `docs/roadmap.md` (supersedes the R0–R18 outcome roadmap); current
posture is in `docs/state.md`. `docs/product-direction.md` (last reviewed 2026-07-05)
still describes the long-term ambition but predates the reset — where they differ,
the roadmap wins.

**Direction**
- Local only for now. Deployment, production-evidence gates, launch market, legal review,
  payments and analytics baselines are deferred until the product feels finished.
- Audience: everyone looking for a job. No one-line promise locked yet (parked on purpose).
- Keep every built feature, but make each one real and visually consistent with the
  original thesis design (dashboard, tool input heroes and result pages are the reference).
- Build on `chapter2`; never go back to `main` (it would lose the backend work).

**What `chapter2` is**
The integration branch (D-027). It holds the thesis app plus the R0–R17 build (#316),
the Aug 2026 roadmap-finish commits (#318), the repo tidy (#317), and the whole reset
run. Feature areas are default-off behind independent flags (#332; no more chained
R11→R17 dependencies); locally they are all switched on via gitignored `.env` files.

**What was kept (and redesigned on the shared workspace shell, #331)**
- **CV Studio (flagship):** import an existing CV → structured entries → customise
  (5 templates, 5 fonts, colours, density, section order) → ATS-safe mode + ATS score →
  tailor to a job → versions → PDF/DOCX export. No "build from scratch" flow (owner's call).
  PRs #334, #339, #340.
- **Job Discovery:** real listings from public Greenhouse, Lever and Ashby GET APIs
  (#337; a local run ingested ~5.8k jobs from 48 companies), search/filters/match score,
  Tailor CV / Add to campaign / Apply buttons (#342).
- **Application Queue:** prepare an application, review it, open the employer's apply
  page, mark as applied (#345). Submission always stays human.
- **Campaigns:** pipeline board Saved → Applied → Interviewing → Offer, tasks, notes (#343).
- **Evidence Profile:** simplified, suggestions to accept, Development plan folded in as
  "Skills to build" (#333, #344). Sidebar grouped Tools / Job search / You.
- **Autopilot (experiment, #346):** local browser-assisted form fill for Greenhouse/Lever/Ashby
  https pages only; never presses submit. Off by default. See the roadmap section on #325.
- **AI provider:** pluggable `LLM_PROVIDER` = `fake` (deterministic local demo, fixtures in
  `backend/app/services/fake_llm.py` — update them when a prompt builder changes) |
  `anthropic` (Haiku 4.5, needs an API key) | `vertex` | `google`. Vertex is not configured.

## Decisions from recent conversations

- **2026-09-18** — Repo tidy (#317): stale branches, worktrees and stashes removed, junk
  folders deleted. Safety net: archive tags on origin (`archive/pre-tidy-20260918`,
  `archive/thesis-review-local`, `archive/r3-security-headers-closed-pr83`).
  *Why:* 80+ local branches made the state unreadable.
- **2026-09-24** — Local-only, feature-first reset. *Why:* no paid hosting; value comes
  from real features, not release ceremony.
- **2026-09-24** — Drop the grill → PRD → issues ceremony and the R0–R18 gates; close the
  R-series issues. *Why:* an audit found 0 of 31 open issues were coding work — all waited
  on owner decisions, real users or legal steps, so they could never close while local-only.
- **2026-09-24** — Keep every feature, fix the UI instead of cutting. *Why:* the old design
  was intact on existing pages; only the new pages were never styled (CV Studio had ~110
  lines of CSS). Fix = reuse the original hero/card/animation components.
- **2026-09-24** — Discovery uses only public employer job-board APIs (Greenhouse, Lever,
  Ashby). *Why:* free and lawful; Polish boards have no official API (scraping breaks terms);
  Adzuna needs a commercial licence.
- **2026-09-24** — No auto-submit; R16 plumbing deleted; Autopilot becomes a small local
  experiment that stops before submit. *Why:* ATS submit APIs require the employer's own key,
  so unattended submission is not lawfully possible; the old plumbing never submitted anything.
- **2026-09-24** — Independent feature flags. *Why:* chained R11→R17 flags made each area
  impossible to enable alone.
- **2026-09-24** — Add `fake` and `anthropic` LLM providers (#329). *Why:* Vertex billing is
  off; `fake` gives a free deterministic demo, Haiku 4.5 is the cheap real option. A chat
  subscription cannot power the app — it needs an API key.
- **2026-09-24** — Cut speculative infrastructure (R7, R8, R9, R10, R16). *Why:* the diff had
  grown to ~94k lines with zero live callers for these systems (D-125).
- **2026-09-24** — Cost-aware agent runs: cheap models for mechanical work, mid-tier for
  building, top-tier only for design/judgement and final review; small workflows (<10 agents).
- **2026-09-25** — Hand off to fresh sessions early (stay well under ~150k context) and do
  the engineering review as sliced `/code-review` + `/improve-codebase-architecture`.
  *Why:* the run reached ~500k context; long sessions degrade.
- **2026-09-25** — Fix the audit with pnpm overrides (#348) rather than upgrading
  `@tanstack/react-start`. *Why:* the advisories were transitive; overrides are the smallest change.
- **2026-09-25** — Boot guard against `LLM_PROVIDER=fake` outside development (this branch).
  *Why:* the fake provider must never answer real users.

Known stale docs: ADR 0009/0010 status lines predate the reset (R16 is deleted; the Queue
hands off to the apply page). `docs/product-direction.md` predates it too.

## How to resume (fresh Mac)

1. **Tools:** Git, GitHub CLI (`gh auth login`), Node 22 (`.nvmrc`) + pnpm 10.30.3,
   Python 3.12 (`.python-version`), PostgreSQL 16. Docker is optional (the gate can skip it).
2. **Clone and check out:**
   ```bash
   gh repo clone gx4004/ai-career-platform && cd ai-career-platform
   git fetch origin && git checkout fix/release-gate-326
   ```
   Keep the clone outside iCloud-synced folders (Desktop/Documents) — that is how the
   last working copy was lost.
3. **Backend env:** `cp backend/.env.example backend/.env`, then set (names only; values
   are local choices or your own keys):
   - Core: `DATABASE_URL`, `SECRET_KEY`, `ENVIRONMENT=development`, `CORS_ORIGINS`, `FRONTEND_URL`
   - AI: `LLM_PROVIDER` (`fake` to start), `LLM_MODEL`, `LLM_PRACTICE_MODEL`,
     `ANTHROPIC_API_KEY` (only for `anthropic`); `GOOGLE_API_KEY`, `VERTEX_PROJECT_ID`,
     `VERTEX_LOCATION` only for those providers
   - Feature flags (all `true` locally): `R11_EVIDENCE_PROFILE_ENABLED`,
     `R12_CV_STUDIO_ENABLED`, `R13_CAMPAIGNS_ENABLED`, `R14_DISCOVERY_ENABLED`,
     `R15_QUEUE_ENABLED`, `R17_DEVELOPMENT_LOOP_ENABLED`, `ATS_INGESTION_ENABLED`,
     `AUTOPILOT_EXPERIMENT_ENABLED` (optional); also review `EVIDENCE_PROFILE_INJECTION_ENABLED`,
     `BLENDED_SCORING_ENABLED`, `RESULT_CACHE_ENABLED`
   - Leave at example defaults / unset locally: `ACCESS_TOKEN_EXPIRE_MINUTES`,
     `REFRESH_TOKEN_EXPIRE_DAYS`, `ALGORITHM`, proxy/rate-limit/abuse settings
     (`TRUST_PROXY_HEADERS`, `TRUSTED_PROXY_CIDRS`, `RATE_LIMIT_*`, `ABUSE_IDENTITY_HMAC_KEY`,
     `AUTH_*`, `ACCOUNT_*`), cost/resource limits (`MODEL_*_LIMIT`, `RESOURCE_*_LIMIT`),
     `RESULT_CACHE_TTL_SECONDS`, `RESULT_CACHE_MAX_ENTRIES`, `CAPTCHA_*`, `GOOGLE_CLIENT_*`,
     `GOOGLE_REDIRECT_URI`, `RESEND_API_KEY`, `PASSWORD_RESET_*`,
     `DISPOSABLE_EMAIL_BLOCK_ENABLED`, `SENTRY_DSN`.
4. **Frontend env:** `cp frontend/.env.example frontend/.env`, uncomment the matching
   `VITE_R11_…`–`VITE_R17_…` flags and optionally `VITE_AUTOPILOT_EXPERIMENT_ENABLED`.
   `VITE_API_URL`, `VITE_SENTRY_DSN`, `VITE_CAPTCHA_SITE_KEY` stay unset;
   `SECURITY_HSTS_ENABLED=false`.
5. **Install deps and migrate:**
   ```bash
   cd backend && python3.12 -m venv .venv && source .venv/bin/activate \
     && pip install -r requirements-dev.txt && alembic upgrade head
   python -m playwright install chromium   # only for the Autopilot experiment
   cd ../frontend && pnpm install --frozen-lockfile && pnpm exec playwright install chromium
   ```
   Optional, to repopulate Discovery: `python -m app.scripts.seed_ats_sources` then
   `python -m app.scripts.ingest_ats_sources` (from `backend/`; sources in `ats_sources.json`).
6. **Run tests** (move `backend/.env` and `frontend/.env` aside first — the all-flags-on
   local env breaks tests that assume defaults):
   ```bash
   cd backend && ruff check app && pytest -q
   cd ../frontend && pnpm typecheck && pnpm test && pnpm build
   ```
7. **Rerun the release gate** against a disposable Postgres database (e.g. `cw_local_release`):
   ```bash
   ./scripts/local-release.sh --preflight
   ./scripts/local-release.sh --allow-missing-docker \
     --database-url postgresql+psycopg2://<user>@127.0.0.1:5432/cw_local_release
   ```
   Then restore the `.env` files and open a PR `fix/release-gate-326` → `chapter2`.
   Merge with `gh pr merge N --squash` and close issues manually (`chapter2` is not the
   default branch, so `Closes #N` does not fire).
8. **Rerun the engineering review** in a fresh session: `/code-review` of `chapter2` vs
   `main`, sliced by area (platform/shared; CV Studio; Discovery + ingestion; autopilot +
   queue + packets; campaigns + evidence + frontend shell), Standards + Spec axes each.
   Then `/improve-codebase-architecture`. Turn findings into issues; one issue per fresh context.
9. **Decide** the three open review findings above, then close #326 and plan the next slice.
